Question: Show five tracks priced at 99 cents.

SQL:
SELECT TrackId, Name, UnitPrice
FROM Track
WHERE UnitPrice = 0.99
ORDER BY Name ASC, TrackId ASC
LIMIT 5

Question: Which albums contain more than 20 tracks?

SQL:
SELECT Album.Title AS album, COUNT(Track.TrackId) AS track_count
FROM Album
JOIN Track ON Album.AlbumId = Track.AlbumId
GROUP BY Album.AlbumId, Album.Title
HAVING COUNT(Track.TrackId) > 20
ORDER BY track_count DESC, album ASC

Question: Show five tracks whose composer is not recorded.

SQL:
SELECT TrackId, Name
FROM Track
WHERE Composer IS NULL
ORDER BY Name ASC, TrackId ASC
LIMIT 5

Question: Which five customers have the most invoices?

SQL:
SELECT Customer.CustomerId, COUNT(Invoice.InvoiceId) AS invoice_count
FROM Invoice
JOIN Customer ON Invoice.CustomerId = Customer.CustomerId
GROUP BY Customer.CustomerId
ORDER BY invoice_count DESC, Customer.CustomerId ASC
LIMIT 5
